# Keyboard shortcuts

**Cmd** means the Command key on macOS and **Ctrl** on Windows/Linux.
Shortcuts marked *Ctrl* use the Control key on every platform.

## Transport

| Action | Shortcut |
|---|---|
| Play / Stop | Space |

## File

| Action | Shortcut |
|---|---|
| New Project… | Cmd+N |
| Open… | Cmd+O |
| Save | Cmd+S |
| Save as… | Cmd+Shift+S |
| Export Audio… | Cmd+Alt+B |
| Settings… | Cmd+, |

## Edit

| Action | Shortcut |
|---|---|
| Undo | Cmd+Z |
| Redo | Cmd+Shift+Z |
| Cut / Copy / Paste | Cmd+X / Cmd+C / Cmd+V |
| Select All | Cmd+A |
| Delete | Delete |
| Split | Cmd+E |
| Duplicate | Cmd+D |
| Auto Edit: Create Segments… | Cmd+1 |
| Auto Edit: Assemble Sequential… | Cmd+2 |
| Auto Edit: Assemble Random… | Cmd+3 |

## Create

| Action | Shortcut |
|---|---|
| Create Audio Track… | Cmd+Shift+N |
| Create Region… | Cmd+R |

## View

| Action | Shortcut |
|---|---|
| Full Screen | Cmd+Ctrl+F |
| Open File Browser | Shift+NumPad 5 |
| Zoom In / Zoom Out | Cmd++ / Cmd+- |
| Page Left / Page Right | ← / → |
| Follow Transport | Ctrl+F |
